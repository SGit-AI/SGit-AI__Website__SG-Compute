sg-compute.sgit.ai

An ephemeral compute platform for AWS: sixteen ready-to-launch workload specs, each launched, worked and terminated in an isolated environment — with every number measured from the tree. Part of the sgit.ai network. All site content CC BY 4.0; the platform's own source is Apache-2.0.

↗ sgit.ai — the parent project and the vault layer this provisions for · ↗ open-source.sgit.ai · ↗ wardley-maps.sgit.ai · ↗ risks.sgit.ai · ↗ the network

sg-compute.sgit.ai is documentation. sg-compute.sgraph.ai is a live Route 53 zone serving per-node DNS. Same label, different TLD, stated deliberately.
